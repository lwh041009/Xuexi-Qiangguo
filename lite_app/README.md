# 学习强国

当前版本 2.11.2，启动工作目录根部的 `学习强国.exe`，构建输出为 `dist/学习强国.exe`。左键单击托盘图标或右键选择“显示窗口”恢复界面。保留 2.11.1 的二维码窗口重复显示修复。阅读、视频、每日答题的选材、时长、作答和计分确认逻辑沿用 2.10。

主窗口的关闭按钮、最小化按钮均只隐藏窗口，不停止任务。左键单击托盘图标或右键选择“显示窗口”恢复；要真正结束程序，请右键托盘图标选择“退出”。Windows 注销或关机仍允许正常退出。

保留登录为尽力恢复：本应用使用独立持久 WebView2 配置目录，并用当前 Windows 用户的 DPAPI 加密备份官方域名 Cookie。启动后仍通过官方用户信息接口校验，失效则重新扫码；不保证平台允许长期登录。要保留登录，请取消“完成后退出登录”并保存设置。重新登录、明确退出登录或确认失效时清除缓存。2.10 使用临时私密会话，不能直接继承其运行中的登录；首次使用新版仍需扫码。不要同时运行两个版本执行任务。

以下为此前版本的行为与历史说明，历史文件名仅用于说明。最终版与源码包已发布到根目录，旧版文件及测试产物已清理；正在运行的 2.11.1 暂留，退出后再删除其目录。

版本 2.10。启动 `学习精简版-2.10.exe` 或 `dist/StudyLite.exe`，主界面显示总积分、今日积分、任务日志、平台进度和开始/停止按钮。登录时单独弹出相对主窗口居中的二维码窗口；每日答题正常作答、跳题和提交均在后台执行，不展示网页窗口。

2.10 仅调整答题窗口显示策略：默认使用与媒体相同的透明浏览器宿主，保持真实渲染，不隐藏 WebView2 控件或篡改网页可见性。检测到验证码或明确需要人工处理的题型时显示答题窗口，处理后恢复后台。停止、提交完成时也恢复后台。阅读、视频时长、选材和计分确认保持 2.9 行为；旧版均保留。

2.9 修复视频选材：官方列表的日期文本现在正确解析，不再全部按 0 排序后退化为按 ID 排序。优先最新内容；同一账号当天未增分的视频排到其他未确认内容后面，不删除历史，也不记为完成。一条视频未增分会尝试下一条，连续三条视频仍未增分才停止。播放查分时长沿用 2.8，不继续盲目延长。真实平台增分仍需实测。

2.8 修正 2.7 在满 60 秒时先暂停视频再查分的时序：满 60 秒开始查分，但未确认增分时继续正常播放，每累计播放 5 秒复查；确认增分就暂停切换，累计播放达到 90 秒仍未增分则暂停停止。短于一分钟的视频正常播完后延迟核对。这个修正不保证平台在 90 秒内给分，真实计分仍需实测。保留 2.7 与更早版本，以及总积分、今日积分显示。

2.6 修复每日答题在“已提交本题，等待页面响应”处卡住的问题：以官方页面实际题号同步内部进度，兼容答对后 1 秒自动跳题和末题自动提交。点击下一题后等待页面题号变化，不再凭点击累加题号；观察到官方提交开始后不重复点“完成”。填空按 `answerId` 匹配输入顺序，重复取题响应不再清空进度。答题诊断只记录题号、数量、状态，不保存题目或答案。2.5 与原程序保持不变。

“设置”中选择阅读、视频、每日答题，默认启用“登录后自动执行”和“静音播放”。可设置“完成后退出登录”，点击“保存设置”保存在本机。点击“开始任务”也可以手动启动；“停止”取消后续调度并暂停已识别的视频。关闭扫码窗口会取消未完成的登录操作。

这是独立重写版，不是原 EXE 的补丁或源代码还原。原文件与之前的 Qt 版本均保留，精简版不依赖 Qt 目录、Python 或源码文件。

## 体积与环境

- 单个 x64 EXE，不打包 Chromium，使用系统的 Microsoft Edge WebView2 Runtime。
- 面向当前这台 Windows 11 x64；需要 .NET Framework 4.8、WebView2 Runtime、Windows 的 `winsqlite3.dll`。没有测试其他电脑或旧版 Windows。
- WebView2 的三个 SDK/loader DLL 内嵌在 EXE 中，首次启动解出到 `%LOCALAPPDATA%\StudyDeskLite\runtime-1.0.3856.49`，约 831 KiB。系统浏览器运行时的安装空间不计入 EXE。
- EXE 未进行 Authenticode 签名。
- 界面默认 620x470，最小 580x440，分为“主页 / 设置”，保留标准窗口关闭与最小化按钮。

## 已接入

- 后台 WebView2 加载官方扫码登录页。只把该会话当前生成的二维码图像显示在独立窗口，不显示整个登录网页，也不使用用户截图中的旧二维码。观察该会话官方域名下的 `__UID__`、`token` Cookie，再通过用户信息接口校验。不使用 HAR 中的凭据，不显示或写日志记录 Cookie/token，不读取外部浏览器。2.11 的加密登录缓存见上文。
- 二维码来自主文档或登录 iframe 的 canvas/image；跨域图片从浏览器已经收到的图像响应中取出，不复制二维码链接进行登录重放。刷新后丢弃旧预览，登录成功/取消后清理内存图片。不保存真实二维码截图。
- 读取 `listScoreProgress?sence=score&deviceType=2`，显示服务器 `currentScore/dayMaxScore`。只对尚未完成的选中任务进行调度。没有返回的任务不冒充完成。
- 自动加载已捕获的 `/lgdata/1hoa55co0nf.json` 内容列表，按 `itemType/type` 筛选文章及单条视频，剔除合集、外链、不安全 URL，按 `itemId` 去重。
- 阅读使用独立透明、无任务栏入口、不激活且不接收鼠标的原生浏览器宿主，保持真实渲染，不再把 WebView2 控件设为隐藏。有正文且检测到真实滚动事件后计时，60 秒起查询平台积分；已增分立即切换，未增分继续浏览并每 10 秒复查，到约 120 秒仍无增分则停止。只有该类平台积分实际增长才进入确认去重记录。本地秒数不代表用户实际阅读，也不等于平台计分；网络查询等待可能使实际墙钟时间更长。
- 视频在后台尝试正常播放，检查主文档及直接 iframe 的 HTML video。播放器就绪后由浏览器实际滚动页面，直到观察到官方日志响应；不是派发合成事件，也不直接调用官网统计函数。实际正常速度累计播放满 60 秒开始查分，不提前暂停；每累计播放 5 秒复查，增分就暂停切换，累计达到 90 秒仍未增分则暂停停止，不记录确认完成。不足一分钟的视频正常结束且累计达到时长 90% 后最多延迟核对约 30 秒。额外检查主文档/播放器可见性、倍速和媒体错误。默认静音。不快进、不伪造播放事件或学习上报。平台日志 HTTP 200 不代表已计分；本地目标时长也不保证平台届时一定计分。查询耗时与缓冲可能延长墙钟时间。
- 总积分读取 `/delegate/score/get` 的 `data.score`；今日积分优先读取任务进度响应 `data.totalScore`，缺失时读取 `/delegate/score/today/query` 的 `data.score`。登录、刷新进度、任务核分时同步读取；今日积分指账号今天累计所得，不限于本软件本轮所得。读取失败显示 `--`；普通退出或登录失效清空，选择完成后退出可保留本轮显示。
- 每日答题自动作答：内置浏览器打开官方答题页后，页面内钩子捕获指定官方 HTTPS 端点、`activityCode=QUIZ_ALL` 的成功取题响应。逐题驱动官方页面控件作答：点选选项（多选题按 `correctAnswerSeq` 顺序）、用原生 value setter 写入填空并派发 input/change 事件，再点击“确定”。根据页面题号同步自动跳题，必要时单次点击“下一题”；末题优先等待官方自动提交。提交后仍以官方提交响应和任务积分确认，合法的 `totalNum=0` 响应不再被误判为结果结构错误；任务是否完成以平台进度为准。
- 每日答题的验证码仍由用户手动处理：检测到验证码才弹出可交互窗口，自动暂停操作并等待，超过现有 150 秒无进展时限则停止。验证码消失后恢复后台自动作答。明确无法自动处理的题型也弹出窗口，页面继续后恢复后台；关闭需要人工处理的窗口会停止任务。媒体任务遇到验证仍停止；身份核验、无法确认结果、页面加载超时或连续不可用内容会停止。

## 当前限制

**每日答题自动作答已通过本地离线验证：五道题覆盖单选、多选、文本填空、判断四类，模拟官方 1 秒自动跳题、末题自动提交，确认仅提交一次；真实账号提交与平台积分确认尚未验收。** Node 回归另覆盖自动跳题状态同步、按 ID 排序的多空输入、重复响应、不重复跳题、端点及活动校验、答案字段脱敏、验证码暂停和停止。已完成规则与 SQLite 测试、阅读和媒体离线验证、二维码测试及窗口切换检查。公开网页测试不带登录凭据并拦截全部 POST，不证明平台接受上报或给予积分。

逐字/选词填空未完成完整兼容与验收，遇到无法识别的题型仍需手动处理。无法核对页面题号时不会盲目作答，超过现有无进展时限会停止。

阅读、视频及正常每日答题不展示网页，仅扫码登录及答题人工处理时显示相应窗口。程序不改写 `document.hidden/visibilityState`。透明宿主不等于真实用户在阅读；平台仍可能要求额外条件。官网统计请求或成绩查询返回 HTTP 成功都不等于已获得积分，最终以平台任务进度为准。

专项试卷尚未接入：现有抓包没有专项列表和完整响应链。不能把每日答题测试当成专项测试。

网页结构或接口可能变化，网关也可能拒绝程序发出的查询；多层 iframe、非 HTML video 播放器、受限文章可能无法识别。浏览器自身可能暂停后台播放，需以实际进度为准。登录失败或接口格式变化会停止，不保证“扫码后必定全部完成”。本轮每种媒体最多尝试 12 条，避免无限循环。

SQLite 保存账号 UID 的 SHA-256 散列、媒体类型、`itemId`、时间、本地时长、前后分数和尝试结果。`credited_visits` 只存积分增长后的确认记录，按账号和条目去重；`attempts` 区分未增分尝试。2.1 的 `visits` 原样保留，但不再把其中仅靠本地计时的记录用于确认去重。数据库位于 `%LOCALAPPDATA%\StudyDeskLite\learning.sqlite3`。积分查询是该类任务总分，不能排除同一账号在其他设备上的操作影响分数。

脱敏诊断在 `%LOCALAPPDATA%\StudyDeskLite\task-diagnostics.jsonl`，记录当前条目、真实滚动事件数、官网日志响应数量/HTTP 状态与前后积分。每日答题另记录提交 HTTP 状态、官方成绩查询响应数量和积分确认状态，不记录题目、答案、请求体、成绩查询标识、Cookie、token、昵称或正文。文件超过 1 MB 时重新开始记录。

视频的单条未增分不会立即中止全部任务，会更换内容，连续三条未增分则停止；所有未增分条目仍是未完成。其他读取失败、验证或播放异常保持现有停止/跳过规则。本轮媒体仍最多尝试 12 条。

2.11 正式运行使用 `%LOCALAPPDATA%\StudyDeskLite\browser-profile`，加密恢复文件为同目录上级的 `login-session.dat`。该备份仅限当前 Windows 用户解密，最长七天；浏览器自身持久 Cookie 遵守原始有效期。Cookie/token 不写进 SQLite、普通设置或诊断日志。离线界面测试仍使用独立 InPrivate 目录；跨进程登录测试使用隔离的持久目录与模拟数据，不访问外网。

## 构建与验证

```powershell
.\build.ps1
.\verify.ps1
.\dist\学习强国.exe --self-test
.\dist\学习强国.exe --smoke-test "$PWD\smoke"
.\dist\学习强国.exe --smoke-test "$PWD\smoke-small" --small
.\dist\学习强国.exe --browser-test "$PWD\browser-test"
.\dist\学习强国.exe --qr-test "$PWD\qr-test"
```

构建脚本使用系统 .NET Framework C# 编译器，以及本机已安装 pywebview 包中随附的 WebView2 SDK/loader DLL；pywebview 本身不参与运行。修改依赖来源时请调整 `build.ps1`。

`--browser-test` 和 `--qr-test` 只使用内存中的模拟页面、题目与公开测试二维码，拦截所有请求，未匹配请求返回 403，不访问外网。截图只绘制本应用窗口，不截取用户桌面，也不会把后台网页拼进主界面。

可选 `--login-probe "$PWD\login-probe"` 访问真实官方登录页，仅验证隐藏会话能取到二维码，输出成功标志，不扫码、不保存真实二维码。它不是完整登录测试。

可选 `--article-probe "$PWD\article-probe"` 在独立临时会话访问一篇公开官方文章，验证正文、真实滚动与统计请求触发。禁止全部 POST 和非官方域名请求，不使用账号、不执行积分任务、不保存正文。

可选 `--video-probe "$PWD\video-probe"` 在独立临时会话对同一公开视频做播放前后对照，验证实际播放增量、真实滚动以及官方初始/周期日志请求被触发。禁止全部 POST，仅允许官方域名和页面使用的 `g.alicdn.com` 静态播放器资源。不使用账号，不保存正文、媒体文件、请求体或凭据，不验证积分。

`verify.ps1` 使用脚本自身的目录构造输出路径，并检查旧结果不能冒充本轮测试。空目录参数只返回错误码并写诊断日志，不弹测试对话框。实际启动失败的诊断位于 `%LOCALAPPDATA%\StudyDeskLite\startup-error.log`；参数异常不会再被笼统提示为缺 WebView2。

第三方组件见 `THIRD_PARTY.md`。此版本不包含原 EXE 的防护排除、更新下载执行、webhook、注册支付或滑块模拟代码。
